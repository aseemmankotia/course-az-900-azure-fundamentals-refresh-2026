# Chapter 6 Lab: Azure Identity, Security, and AI Services (2026 Update)

**Estimated time:** 15 minutes

## Exercise

Navigate Azure portal to Entra ID (formerly Azure AD), explore Users and Groups, then open Azure AI services in the portal to view available AI offerings including Azure OpenAI Service, and review Microsoft Defender for Cloud recommendations on the free tier

## Key takeaway

RBAC controls access permissions, Azure Policy enforces compliance rules, resource locks prevent changes; Microsoft Entra ID provides authentication (MFA, SSO, Conditional Access); Azure OpenAI Service provides large language models for AI applications.
