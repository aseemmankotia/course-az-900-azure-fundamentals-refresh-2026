# Chapter 1 Lab: Cloud Computing Fundamentals and Shared Responsibility

**Estimated time:** 8 minutes

## Exercise

Explore Azure free account creation and navigate the Azure portal home page to identify subscription, resource groups, and cost management sections

## Key takeaway

Shared responsibility model divides security tasks: Microsoft always secures physical infrastructure, customer always controls data classification, and the boundary shifts based on IaaS/PaaS/SaaS.
