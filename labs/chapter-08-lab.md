# Chapter 8 Lab: Azure Governance, Monitoring, and Management Tools

**Estimated time:** 12 minutes

## Exercise

Navigate Azure Advisor to review cost, security, reliability recommendations; explore Azure Service Health to view current service issues; create a simple resource lock on a test resource group to prevent deletion

## Key takeaway

Azure Policy enforces compliance rules (WHAT can be deployed), RBAC controls permissions (WHO can deploy), resource locks prevent changes (deletion/modification); Azure Advisor recommends optimizations, Service Health shows Azure outages, Monitor collects metrics.
