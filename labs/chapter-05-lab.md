# Chapter 5 Lab: Azure Compute, Networking, and Storage Services

**Estimated time:** 18 minutes

## Exercise

Create a storage account in Azure portal, select LRS redundancy and Hot tier, upload a test file to Blob storage, then use Azure pricing calculator to compare storage costs for Hot vs Cool vs Archive tiers for 1TB over one year

## Key takeaway

ExpressRoute is private dedicated connection (not over internet), Archive storage tier is cheapest for rarely accessed data (rehydration takes hours), and GRS replicates to secondary region for disaster recovery.
