# Chapter 3 Lab: IaaS, PaaS, SaaS and Cloud Service Models

**Estimated time:** 12 minutes

## Exercise

Navigate Azure Marketplace to identify IaaS offerings (Windows Server VM), PaaS offerings (App Service), and explore Microsoft 365 admin portal as a SaaS example, noting configuration differences

## Key takeaway

IaaS gives maximum control (you manage OS), PaaS abstracts infrastructure (Microsoft manages OS), and SaaS provides ready-to-use applications (Microsoft manages everything except your data and users).
