# Chapter 7 Lab: Azure Cost Management and Pricing

**Estimated time:** 15 minutes

## Exercise

Use Azure Pricing Calculator to estimate monthly costs for a sample workload (2 VMs, 1TB storage, 500GB egress), then use TCO Calculator to compare 3-year cost of running same workload on-premises vs Azure including power, cooling, labor costs

## Key takeaway

Use TCO Calculator for on-premises vs Azure migration decisions, Pricing Calculator for estimating new Azure workloads, and Cost Management for monitoring actual spending; reserved instances save money with 1-3 year commitment.
