## Chapter 2: Cloud Benefits: Availability, Scalability, and Reliability — Flashcards

| # | Front (Question) | Back (Answer) |
|---|-----------------|---------------|
| 1 | 99.9% SLA = how many minutes downtime per month? | 43.2 minutes per month (43 minutes for exam purposes). Calculation: 30 days × 24 hours × 60 minutes × 0.1% = 43.2 minutes. Exam tip: 99.9% = ~43 min/month, 99.99% = ~4 min/month, 99.999% = ~26 sec/month |
| 2 | Vertical scaling vs Horizontal scaling - which is which? | Vertical = Scale UP/DOWN (bigger/smaller VM: 4 vCPU → 8 vCPU). Horizontal = Scale OUT/IN (more/fewer VMs: 2 VMs → 5 VMs). Exam tip: UP/DOWN = Vertical, OUT/IN = Horizontal. Vertical has limits, horizontal is nearly unlimited. |
| 3 | Scalability vs Elasticity - key difference for exam? | Scalability = ability to handle increased load (manual or automatic). Elasticity = AUTOMATIC scaling both up AND down based on demand. Exam tip: If question mentions 'automatic' and 'reduces resources when not needed' → Elasticity. If just 'handle more load' → Scalability. |
| 4 | Availability Set SLA percentage? | 99.95% for VMs deployed in an Availability Set with 2+ instances. Requires: 2+ VMs, 2+ fault domains, 2+ update domains. Exam tip: Availability Set = 99.95%, Availability Zone = 99.99%, Single VM with Premium SSD = 99.9% |
| 5 | Availability Zones SLA percentage? | 99.99% for VMs deployed across 2+ Availability Zones. Zones are physically separate datacenters within a region (minimum 3 per region). Exam tip: Zones (99.99%) > Sets (99.95%). Zones = different buildings, Sets = different racks in same building. |
| 6 | Fault tolerance vs Disaster recovery - which is which? | Fault tolerance = continue operating during component failure (no downtime). Disaster recovery = restore operations after major failure (some downtime acceptable). Exam tip: Fault tolerance = zero downtime goal (expensive). DR = acceptable downtime (cheaper). RTO/RPO relate to DR. |
| 7 | What are RTO and RPO? | RTO (Recovery Time Objective) = maximum acceptable downtime. RPO (Recovery Point Objective) = maximum acceptable data loss time. Exam tip: RTO = how long until recovered. RPO = how much data can you lose. Lower RTO/RPO = more expensive DR solution. |
| 8 | Predictability in cloud computing - two types? | Performance predictability = consistent application behavior (autoscaling, load balancing). Cost predictability = forecast and control spending (Azure Cost Management, Reserved Instances). Exam tip: Predictability questions test both aspects - stable performance AND known costs. |
| 9 | Azure Policy vs Azure RBAC - when to use which? | RBAC = WHO can do WHAT (permissions, user access). Policy = WHAT configurations are allowed (enforce standards, compliance). Exam tip: User access question → RBAC. Resource configuration enforcement → Policy. Both work together for governance. |
| 10 | Single VM with Premium SSD - what SLA? | 99.9% SLA for single instance VM using Premium SSD or Ultra Disk for all disks. No SLA if using Standard HDD/SSD. Exam tip: Single VM can have SLA if premium storage. Multi-VM setups (Availability Set/Zones) provide higher SLAs. |
| 11 | Maximum downtime per year for 99.99% SLA? | 52.56 minutes per year (4.32 minutes per month). Calculation: 365 × 24 × 60 × 0.01% = 52.56 minutes. Exam tip: Remember monthly numbers: 99.9% = 43 min, 99.99% = 4.3 min. Multiply by 12 for annual. |
| 12 | Cloud manageability - two meanings for exam? | 1) Management OF the cloud = manage resources (scale, deploy, monitor via portal/CLI/APIs). 2) Management IN the cloud = cloud-based management tools (Azure portal, mobile app, automation). Exam tip: Questions may ask about either - 'managing resources' vs 'using cloud tools to manage'. |
