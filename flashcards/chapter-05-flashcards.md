## Chapter 5: Azure Compute, Networking, and Storage Services — Flashcards

| # | Front (Question) | Back (Answer) |
|---|-----------------|---------------|
| 1 | Azure Archive storage tier: minimum storage duration and rehydration time? | 180 days minimum (early deletion fee if sooner). Rehydration: up to 15 hours for high priority, 10 hours for standard. Exam tip: Archive = cheapest ($0.00099/GB), slowest access. Use for data accessed <1x per year. |
| 2 | When to use Azure App Service vs Azure Functions? | App Service: continuous web apps, always-on requirements, need deployment slots, VNet integration. Functions: event-driven, sporadic workload, pay-per-execution, < 10 min execution (Consumption plan). Exam trap: Functions Premium plan costs similar to App Service. |
| 3 | VPN Gateway vs ExpressRoute: key differences exam tests? | VPN Gateway: encrypted over public internet, up to 10 Gbps (VpnGw5), $0.04-$0.50/hour. ExpressRoute: private connection (not internet), up to 100 Gbps, predictable latency, $50-$10,000+/month. Exam: ExpressRoute = 'private' or 'predictable latency', VPN = 'encrypted' or 'quick setup'. |
| 4 | Azure Storage redundancy: LRS, ZRS, GRS, GZRS — how many copies and where? | LRS: 3 copies in 1 datacenter. ZRS: 3 copies across 3 zones in region. GRS: 3 local + 3 in paired region (6 total). GZRS: 3 across zones + 3 in paired region (6 total). Exam tests: which survives datacenter vs zone vs region failure. |
| 5 | Azure Container Instances vs Azure Kubernetes Service: when to use each? | ACI: simple containers, burst/batch jobs, no orchestration needed, per-second billing. AKS: microservices, multi-container apps, need orchestration/scaling/service mesh, Kubernetes expertise. Exam: ACI = 'simplest' or 'no orchestration', AKS = 'complex apps' or 'Kubernetes'. |
| 6 | Virtual network peering: bandwidth limit and encryption? | No bandwidth limit (uses Microsoft backbone). Traffic automatically encrypted over Microsoft network. Regional peering: same region. Global peering: across regions ($0.035/GB). Exam tip: peering is fastest/cheapest VNet-to-VNet connection. |
| 7 | Azure Storage tiers: Hot, Cool, Archive — access frequency and early deletion fees? | Hot: frequent access, no min duration. Cool: <1x/month access, 30-day min (early deletion fee). Archive: <1x/year, 180-day min (early deletion fee). Exam tests: matching access pattern to tier, calculating cost with early deletion. |
| 8 | VM availability sets vs VM scale sets: what do they solve? | Availability sets: protect against rack/hardware failure within datacenter (fault domains + update domains), manual VM management. Scale sets: automatic scaling, identical VMs, load balanced. Exam: availability sets = 'high availability', scale sets = 'autoscale'. |
| 9 | Azure Blob Storage access tiers: can you change after upload? | Yes. Can change between Hot/Cool anytime (instant). Hot/Cool to Archive = rehydration required (up to 15 hours). Archive to Hot/Cool = rehydration (copy or change tier). Exam gotcha: rehydration time and early deletion penalties. |
| 10 | When does exam recommend ExpressRoute over VPN Gateway? | ExpressRoute when: need private connection (not internet), predictable latency required, >1 Gbps bandwidth, hybrid cloud workloads, compliance requires private WAN. VPN when: budget-constrained, temporary connection, quick setup needed, <1 Gbps sufficient. |
| 11 | Azure Virtual Desktop: what's included in the service vs what you pay for separately? | Included: VDI infrastructure, gateway, broker, management. Pay separately: VMs (compute), storage for user profiles, networking egress, Windows licenses (unless you have existing licenses with Azure Hybrid Benefit). Exam trap: thinking AVD itself has compute cost. |
| 12 | GRS vs RA-GRS storage redundancy: what's the difference? | Both replicate to secondary region. GRS: secondary is read-only during failover only. RA-GRS: secondary is always readable (Read Access). RA-GZRS: zone-redundant primary + read access to geo-replicated secondary. Exam tests: when you need read access during primary region outage. |
