## Chapter 1: Cloud Computing Fundamentals and Shared Responsibility — Flashcards

| # | Front (Question) | Back (Answer) |
|---|-----------------|---------------|
| 1 | In IaaS, PaaS, and SaaS, who is ALWAYS responsible for data classification and accountability? | Customer - always responsible for data in ALL service models. Exam tip: Data, accounts/identities, and endpoints are ALWAYS customer responsibility regardless of IaaS/PaaS/SaaS. |
| 2 | Which cloud service model requires customer to manage OS patching: IaaS, PaaS, or SaaS? | IaaS only. PaaS and SaaS = Microsoft patches OS. IaaS = customer controls and patches OS. Exam tip: If question mentions 'control over OS' or 'custom OS configuration' → answer is IaaS. |
| 3 | Define CapEx in cloud economics. | Capital Expenditure: Upfront cost to purchase physical infrastructure. Examples: servers, datacenter, networking equipment. One-time large payment, then depreciates over time. Exam tip: CapEx = traditional on-premises model. |
| 4 | Define OpEx in cloud economics. | Operational Expenditure: Ongoing cost to use services, pay-as-you-go. No upfront cost, only pay for what you consume. Examples: cloud VMs, storage (charged monthly/hourly). Exam tip: OpEx = consumption-based cloud pricing model. |
| 5 | Scenario: Company needs Azure AND on-premises working together. Which cloud deployment model? | Hybrid cloud. Combines on-premises infrastructure with public cloud (Azure). Common exam scenario: 'keep data on-premises but use Azure services' = hybrid. Exam tip: Look for keywords 'both', 'integrate on-premises with Azure'. |
| 6 | Public cloud vs Private cloud: key difference? | Public = resources shared among multiple organizations (multi-tenant). Private = dedicated resources for single organization only. Exam tip: Private cloud can be on-premises OR hosted by third-party, but dedicated to one org. |
| 7 | In shared responsibility model, who manages physical datacenter security in ALL service models? | Microsoft - always. Physical hosts, network, datacenter = Microsoft in IaaS, PaaS, SaaS. Exam tip: Anything 'physical' = Microsoft responsibility. |
| 8 | Customer deploys Azure VM (IaaS). Who is responsible for network controls (NSGs, firewalls)? | Customer configures network controls. Microsoft provides the tools (NSGs, Azure Firewall), customer configures the rules. Exam tip: In IaaS, customer controls networking configuration, even though Microsoft provides infrastructure. |
| 9 | Consumption-based model: what are you charged for? | Only what you actually use (compute hours, storage GB, data transfer). No upfront cost. Scale to zero = $0 cost. Exam tip: Opposite of reserved/fixed pricing. Best for variable/unpredictable workloads. |
| 10 | Azure App Service (PaaS): who manages runtime environment (.NET, Java, Python)? | Microsoft manages and updates runtime. Customer selects which runtime, Microsoft maintains it. Exam tip: PaaS = Microsoft manages OS + runtime + patching. Customer manages only app code and data. |
| 11 | Multi-cloud definition and example. | Using services from multiple cloud providers simultaneously (e.g., Azure + AWS). Different from hybrid (cloud + on-premises). Exam tip: Multi-cloud = multiple PUBLIC clouds. Hybrid = public cloud + private/on-premises. |
| 12 | SaaS example: Office 365. What is customer responsible for? | Only data, user accounts, and access controls. Microsoft manages everything else (app, OS, infrastructure). Exam tip: SaaS = least customer responsibility. Customer manages ONLY: data, users, devices/endpoints. |
