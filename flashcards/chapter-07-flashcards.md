## Chapter 7: Azure Cost Management and Pricing — Flashcards

| # | Front (Question) | Back (Answer) |
|---|-----------------|---------------|
| 1 | Azure Pricing Calculator vs TCO Calculator — when to use each? | Pricing Calculator: estimate costs for NEW Azure workloads (e.g., 'What will 5 VMs + SQL DB cost monthly?'). TCO Calculator: compare on-premises vs Azure over 3-5 years for migration ROI (includes datacenter exit costs, power, cooling, IT labor). Exam tip: TCO = migration decision, Pricing = new workload estimate. |
| 2 | Three main factors that affect Azure resource costs? | 1) Resource type (VM SKU, storage tier, database tier). 2) Consumption (hours used, GB stored, transactions). 3) Region (West US cheaper than North Europe for same VM). Exam tip: region pricing differences heavily tested — same VM costs more in some regions. |
| 3 | Spot VMs discount percentage and use case? | Up to 90% discount vs pay-as-you-go. Use case: interruptible workloads (batch jobs, dev/test, stateless processing). Can be evicted with 30-second notice. Exam trap: NEVER use Spot for production workloads requiring guaranteed availability. |
| 4 | Reserved VM Instance discount percentages for 1-year vs 3-year? | 1-year RI: ~40% savings. 3-year RI: up to 72% savings. Requires commitment to VM size, region, and term. Best for: consistent 24/7 workloads. Exam tip: Reservations save more than Hybrid Benefit (40%) but require capacity commitment. |
| 5 | Purpose of tags in Azure cost management? | Tags enable cost allocation and filtering. Example: tag resources with 'Department: Finance' then filter Cost Management reports by tag to see Finance spending. Use case: departmental chargebacks. Exam tip: tags are the recommended method for cost tracking, not separate subscriptions. |
| 6 | Azure Cost Management budgets — what happens when exceeded? | Budgets send ALERTS only — they don't stop resource deployment or usage. Configure alerts at thresholds (e.g., 80%, 100%, 120%). To actually prevent spending, combine with Azure Policy or automation scripts. Exam trap: budgets ≠ spending caps. |
| 7 | What is right-sizing and when does Azure Advisor recommend it? | Right-sizing = matching VM size to actual utilization. Advisor recommends downsizing when CPU < 10% or memory underutilized over 7 days. Example: D4s (4 vCPU) to D2s (2 vCPU) if CPU averages 15%. Saves ~50% cost. Exam tip: right-sizing is a cost optimization strategy, not a pricing model. |
| 8 | Azure Hybrid Benefit — what is it and savings percentage? | Brings existing Windows Server or SQL Server licenses with Software Assurance to Azure. Saves up to 40% on VM costs. Applies to: Windows Server VMs, SQL Database, SQL Managed Instance. Exam tip: Hybrid Benefit < Reserved Instances savings (72%). |
| 9 | Pay-as-you-go vs Reserved Instance — pricing model difference? | Pay-as-you-go: no commitment, pay hourly, full price, flexibility to stop anytime. Reserved Instance: 1 or 3-year commitment, 40-72% discount, pay upfront or monthly, locked to region/VM size. Exam scenario: 24/7 workload = RI. Variable workload = pay-as-you-go. |
| 10 | Why do identical VMs cost different amounts in different Azure regions? | Regional pricing reflects datacenter operational costs, local infrastructure expenses, and market conditions. Example: West US often cheaper than North Europe or Japan East for same VM SKU. Exam tip: region = cost factor; always check Pricing Calculator for target region. |
| 11 | Top 3 cost-saving strategies for existing Azure workloads? | 1) Right-size VMs (downsize underutilized resources). 2) Auto-shutdown for dev/test VMs (schedule stop at night/weekends). 3) Reserved Instances for 24/7 production workloads. Bonus: delete unused resources, use Cool/Archive storage tiers. Exam tip: strategy must match workload type. |
| 12 | Microsoft Cost Management + Billing — primary purpose? | Track and analyze actual Azure spending for deployed resources. Features: cost analysis, budgets, alerts, export billing data, departmental views using tags. Exam distinction: analyzes EXISTING spending, doesn't estimate future costs (that's Pricing Calculator). |
