## Chapter 6: Azure Identity, Security, and AI Services (2026 Update) — Flashcards

| # | Front (Question) | Back (Answer) |
|---|-----------------|---------------|
| 1 | What's the difference between RBAC, Azure Policy, and Resource Locks? | RBAC = WHO can do WHAT (permissions). Azure Policy = WHAT configurations are allowed/required (compliance). Resource Locks = PREVENT deletion/modification (change prevention). Exam tip: RBAC for access control, Policy for standards enforcement, Locks for protection against accidental changes. |
| 2 | Microsoft Entra ID B2B vs B2C - when to use which? | B2B = Business partners/external organizations collaborate with your employees. B2C = Customers/consumers sign into your public-facing app using social IDs (Google, Facebook). Exam tip: B2B for partners, B2C for customers. |
| 3 | Three core principles of Zero Trust security model? | 1) Verify explicitly (always authenticate/authorize). 2) Least privilege access (minimum necessary permissions). 3) Assume breach (minimize blast radius, verify end-to-end). Exam tip: Zero Trust = never trust, always verify, regardless of location. |
| 4 | What is single sign-on (SSO) in Microsoft Entra ID? | Authenticate once, access multiple applications without re-entering credentials. Works across Azure Portal, Microsoft 365, and integrated SaaS apps. Exam tip: SSO reduces password fatigue and improves security by minimizing credential exposure. |
| 5 | What do Conditional Access policies evaluate? | Signals: user/location/device/app/risk level. Actions: allow access, require MFA, block access. Exam tip: Use Conditional Access to require MFA from untrusted locations or unmanaged devices while allowing normal access from corporate networks. |
| 6 | Passwordless authentication methods in Microsoft Entra ID? | Windows Hello for Business, FIDO2 security keys, Microsoft Authenticator app (phone sign-in). Exam tip: Passwordless eliminates password-based attacks and improves user experience - more secure than passwords + MFA. |
| 7 | Microsoft Defender for Cloud: CSPM vs CWPP? | CSPM (Cloud Security Posture Management) = identify misconfigurations, vulnerabilities, recommendations, secure score. CWPP (Cloud Workload Protection) = threat detection, security alerts, incident response. Exam tip: CSPM for prevention, CWPP for detection/response. |
| 8 | When to use Azure OpenAI Service vs Cognitive Services Language? | Azure OpenAI = generative AI, complex conversational AI, content generation, advanced reasoning (GPT-4). Cognitive Services Language = pre-built NLP APIs for sentiment analysis, key phrase extraction, entity recognition. Exam tip: Language service for specific NLP tasks, OpenAI for generative/complex scenarios. |
| 9 | Six Microsoft Responsible AI principles? | 1) Fairness 2) Reliability and Safety 3) Privacy and Security 4) Inclusiveness 5) Transparency 6) Accountability. Exam tip: Remember FRPITA or Fair, Reliable, Private, Inclusive, Transparent, Accountable systems. |
| 10 | What is defense-in-depth security strategy? | Multiple layers of security controls: Physical → Identity → Perimeter → Network → Compute → Application → Data. If one layer fails, others provide protection. Exam tip: Different from Zero Trust - defense-in-depth is about layers, Zero Trust is about verification and least privilege. |
| 11 | Microsoft Copilot family - three main offerings as of 2026? | 1) Microsoft 365 Copilot (productivity in Word, Excel, Teams). 2) GitHub Copilot (code completion, AI pair programming). 3) Copilot in Azure (infrastructure management assistance in Azure Portal). Exam tip: Copilots are AI assistants integrated into specific Microsoft products. |
| 12 | Azure Cognitive Services vs Azure Machine Learning - when to use which? | Cognitive Services = pre-built AI APIs, no ML expertise needed (Vision, Speech, Language, Decision). Azure ML = build/train/deploy custom models, requires data science skills. Exam tip: Use Cognitive Services unless you need a custom model for specific use case. |
